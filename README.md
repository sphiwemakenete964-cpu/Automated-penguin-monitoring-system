# Automated Penguin Monitoring System (APMS)

## Project Overview

The Automated Penguin Monitoring System (APMS) is an engineering project focused on developing an electronic monitoring system for penguin weighing stations.

The project involves the integration of electronic hardware, measurement systems, communication modules and a Raspberry Pi-based interface.

This repository documents the engineering work, hardware development and PCB design associated with the project.

## Project Objectives

- Develop electronic hardware for the monitoring system.
- Interface with load-cell-based weighing equipment.
- Implement current monitoring.
- Support GSM-based communication.
- Integrate the electronics with a Raspberry Pi.
- Document the hardware design and testing process.

## Hardware and Technologies

- Raspberry Pi
- Arduino-based monitoring electronics
- Load-cell measurement system
- GSM communication (SIM800L)
- Power supply circuitry
- Custom PCB development using KiCad

*The technologies listed describe the project context; individual implementation details will be documented as they are verified.*

## Repository Contents
